# Rohit Borole — Personal Portfolio

Responsive portfolio built with HTML5, CSS3 and Bootstrap 5.

## Run locally
Open `index.html` in a browser. Bootstrap is loaded from its CDN, so an internet connection is needed for Bootstrap's responsive navbar behavior and styles.

## Sections
Home, About Me, Skills, Featured Projects, Contact form.

> Replace any skill levels or profile wording with your exact details before submission if needed.
